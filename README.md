# Online-Examination-System
A Java Swing-based Online Examination System with student registration and a 60-second timed MCQ exam. Uses ArrayList, OOP concepts, event handling, Swing components, Timer, and JOptionPane. Student details are stored locally in a text file, with automatic result calculation and pass/fail evaluation.
System Workflow
Student Registration – The student enters their name, student ID, and email.
Save Student Details – The details are stored in a text file.
Start Exam – The student gets 10 multiple-choice questions with a 60-second timer.
Answer Questions – The student can move between questions using Previous and Next.
Submit Exam – The exam is submitted manually or automatically when the timer reaches zero.
Calculate Result – The system checks the answers and calculates correct, wrong, unanswered, percentage, and pass/fail.
Display Result – The final result is shown to the student using a message box.
